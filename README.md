# Organic Reaction Tutor

Create the hosted Organic Reaction Drawing Practice pilot described in this conversation: five SN1/SN2/E1/E2 major-product drawing questions, a real Ketcher editor, server-side molecular structure grading, immediate feedback, no accounts or saved attempts, and a teal college-level design. Do not expose answer keys in frontend code and do not claim chemistry grading works unless the grading service is fully configured.
